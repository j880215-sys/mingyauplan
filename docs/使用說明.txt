照顧計畫產生器　使用說明（版本 {ver}）
新北市私立明曜居家長照機構社區整合型中心專用
==================================================

【這是什麼】
家訪時在平板或電腦上點選「A單位個案管理員 家庭訪視評估表」，
程式會同步寫出可貼進衛福部照顧管理系統（CMS）的「計畫目標」與「計畫執行規劃」兩欄文字。
整個程式只有一個檔案，完全離線，不連網路、不上傳任何資料。

【資料夾內容】
照顧計畫產生器.html　程式本體
使用說明.txt　　　　　本說明
個案存檔／　　　　　　存檔資料夾，內含「115年度／1月～12月」等子資料夾

【電腦上開啟】
1. 先把壓縮檔解壓縮，整個資料夾放到電腦上。
2. 用 Chrome 或 Edge 開啟「照顧計畫產生器.html」（點兩下即可）。
3. 第一次使用先按「設定」，填入個管員姓名，之後新個案會自動帶入。

【iPad 上開啟】（目前尚未在實體 iPad 上測試，請試用後告知結果）
iPad 的 Safari 無法直接開啟「檔案」App 裡的 HTML 檔。可行的方式還在確認中，
請先在電腦上使用，或回報您單位可用的方式（例如單位內部網站、可開啟本機網頁的 App），
我們再依實際環境調整。

【一次訪視的流程】
1. 按「新增個案」。複評時在清單上按「複製為複評」，會帶入上次內容，只改有變動的地方。
2. 依左側 壹 → 貳 的分頁點選評估內容；每頁右側（平板在畫面底部）會即時顯示這一段的計畫文字。
3. 「參　照顧問題」：依 CMS 上照專核定的 34 項照顧問題清單勾選，調整說明文字。
4. 「肆　服務規劃」：選服務碼、頻率、備註，每月單位數會自動換算，也可以直接改。
   喘息／短照會依 CMS 等級自動帶入年度單位數上限（例：第2～6級 GA09 42 單位、第7～8級 63 單位）。
5. 「計畫目標」：依服務內容先擬一版短中長期目標，按「換一種寫法」可切換 3 種句型。
6. 「產生計畫」：看檢查提醒（按「前往填寫」會直接跳到未填的欄位），
   再分別按「複製計畫目標」「複製計畫執行規劃」貼到 CMS。
7. 按右上角「存檔」，存出「○○○訪視評估表」與「○○○計畫內容」兩個檔案。

【複評】
在個案清單按「複製為複評」，修改有變動的地方後，到「產生計畫」：
- 程式會和前次紀錄比對，自動寫出「本次複評體況」與「與前次計畫不同之處」，可再修改。
- 完整版：依壹～肆重寫，開頭為「○年○月○日複評家訪」。
- 摘要版：只寫體況變化與計畫差異，貼在 CMS 原內容最上方。

【計畫異動】
開啟個案 → 到「服務規劃」改成異動後的服務 → 到「計畫異動」填日期、原因、討論對象
→ 複製兩段文字，分別貼在 CMS 兩個欄位的最上方（原本的內容留在下面）。

【存檔與資料夾】
- 電腦（Chrome、Edge）：第一次按「存檔」時，選擇本資料夾內的「個案存檔」，
  之後會依訪視日期自動存進「115年度／11月」這類子資料夾。
- iPad：按「存檔」會跳出分享選單，選「儲存到檔案」再自行選資料夾（Safari 無法自動分資料夾）。
- 「訪視評估表」檔可以列印，也可以在任何一台裝置用首頁「匯入訪視評估表檔」重新開啟編輯。
- 程式也會把最近編輯的個案暫存在這台裝置的瀏覽器裡，但清除瀏覽器資料就會消失，請以存檔為準。
- 個案檔含有個資，請勿用通訊軟體或公開雲端傳送；共用裝置用完請從清單刪除。

【交給同事使用】
- 把整個資料夾壓縮後傳給同事，解壓縮即可使用，不需安裝。
- 每個人的個案資料各自存在自己的裝置，不會互通。
- 想沿用同一套設定（交通服務單位、自訂服務項目、單位換算）：
  在「設定」按「匯出設定檔」，同事在「設定」按「匯入設定檔」。

【資料來源】
- 服務碼別：全國法規資料庫「長期照顧服務申請及給付辦法」（114年6月19日修正）
  附表四 照顧組合表、附表四之一 智慧科技輔具，共 166 項。
- 輔具免評估／需評估：依附表四各項說明（「得由輔具供應人員逕行提供」為免評估；
  「應由輔具評估人員出具評估報告」及居家無障礙 F 碼、智慧科技輔具 EI 碼為需評估）。
  ED08 移位機吊帶附表未載明，歸在需評估，請核對。
- 喘息額度：附表二（第2～6級 32,340 元／年、第7～8級 48,510 元／年），GA09 單價 770 元。
- 短照（SC 碼）不在給付辦法附表內。額度（第2～6級 87,780 元＝SC09 114組、第7～8級 71,610 元＝93組）
  經單位確認；SC 碼名稱取自地方政府公開資料，請以 CMS 顯示為準。
- 交通接送服務單位：新北市長照特約單位名單（115年9月9日版）中，可服務泰山區的 21 個單位；按鈕與計畫文字使用單位指定的簡稱（兩家大豐分寫為大豐國際、大豐交通）。
- 身心障礙類別：身心障礙者權益保障法第5條（第一類～第八類）。
- 照顧問題清單 34 項、每月單位換算（每週1天5、2天9、3天14、4天18、5天23、6天27、每日31）：經單位確認。
